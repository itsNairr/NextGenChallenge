# Project Instructions

## Architecture Rules
- Use a composable structure for all frontend code.
- Place reusable state and domain logic in `src/composables/`.
- Keep user interface components small, focused, and composable.
- Write clean TypeScript code with explicit types.

## Comment Rules
- Write single-line comments only (`// ...`).
- Do not write multi-line comments.
- Keep comments brief and informative.

## Communication Rules
- Use Simplified Technical English (STE) when communicating with the user.
- Write short, clear sentences.
- Use active voice.
- Avoid idioms, metaphors, and complex sentence structures.
- Keep each statement focused on a single point.
